# Organisation du dépôt Dark Nova RP

- `public/` : interface, graphismes et modules du navigateur.
- `server.mjs` et les autres modules `.mjs` à la racine : serveur et règles du jeu.
- `*.test.mjs` : tests conservés à leur emplacement actuel pour préserver leurs imports.
- `docs/` : notes des versions et consignes de déploiement.
- `Dockerfile`, `package.json` et les fichiers d’exclusion : configuration du projet et de l’hébergement.

Les copies, anciennes versions complètes et installateurs ont été archivés hors du dépôt, avec une sauvegarde complète et un journal des déplacements. Le dossier `.git` et le code actif sont conservés.

Le tri correspond uniquement à des changements locaux. Aucun commit, push GitHub ou déploiement Railway n’a été lancé par ce rangement.
